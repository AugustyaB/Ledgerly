# 📜 Ledgerly — Changelog & Version History

All notable changes and version milestones for Ledgerly will be documented in this file.

The project follows a semantic versioning approach for its alpha and production releases:
- **v0.1.x series**: Alpha foundation milestones.
- **v0.2.x series**: Next planned development cycle (commencing after the conclusion of v0.1.3).

---

## [0.1.3] - Current Alpha Milestone
> *Formerly referenced during initial development as v1.3*

### Focus: Working on fine-tuning the app
- **Refinement & Polish**: Fine-tuning application workflows, transaction inputs, category mappings, and error handling.
- **Foresight & Ambient Intelligence**: Testing and calibrating ambient financial insights and budget alert thresholds.
- **Persistence & Performance**: Verifying offline data integrity, local JSON storage stability, and receipt image attachments.

---

## [0.1.2] - Historical Milestone
> *Formerly referenced during initial development as v1.2*

### Focus: Defining the DLS and the overall visuals of the software
- **Design Language System (DLS)**: Adopted and implemented **Theme 3 ("The Modern Indian Household")** with a Graphite dark slate base and Spiced Chai Amber accents.
- **Typography & Vector Iconography**: Standardized on Inter typography, JetBrains Mono for numbers/currency, and bundled Lucide vector icons.
- **Visual Overhaul**: Designed multi-section financial workspaces, custom monogram avatars, and responsive navigation layouts.
- **Visual Decisions**: Documented architectural decisions in `DECISIONS.md` (ADR-001 through ADR-006).

---

## [0.1.1] - Historical Milestone
> *Formerly referenced during initial development as v1.1*

### Focus: Making the base of the app
- **Core Architecture**: Established the 100% offline Electron desktop runtime.
- **Expense Ingestion Engine**: Built the initial transaction data model, natural language expense parser, and category matching.
- **Multi-Profile System**: Implemented multi-profile household user selection and local file storage.
- **Initial Prototype**: Basic UI, quick pill drawer, and receipt storage foundations.

---

## Planned Upcoming Roadmap
- **v0.2.0**: Commencing next phase of work following the conclusion of v0.1.3 fine-tuning.
